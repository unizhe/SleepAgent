# HealthClaw reference

HealthClaw was reviewed as external design context for governed longitudinal health memory and multi-role care collaboration. The prior local MinerU extraction was removed because it duplicated an external paper and mixed generated artifacts with maintained repository documentation. Historical SleepAgent decisions influenced by the review remain under `docs/audits/memory-governance/`.
