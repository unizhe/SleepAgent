# Historical engineering evidence

Everything below this directory describes an earlier checkpoint. It is retained for provenance and is not authoritative current architecture.

- `plans/` — repository restructuring/remediation plans and review logs.
- `remediation/` — public-safe ADRs, baselines, and remediation notes.
- `audits/` — earlier P4 final/consolidation reports.
- `pre-closure/` — superseded Perceptor, G8, G9, and G10 current-looking documents preserved unchanged at public closure.
- `public-closure-build-log.md` — implementation and verification transcript for this closure.

Start with the [current documentation index](../README.md).

The original execution ledger and PostgreSQL verification baseline remain byte-for-byte in the owner-local audit area rather than the public tree because they contain absolute workstation paths.
